# Audited Stage 2 experiment protocol

This protocol is declared before the final comparisons. The expected architecture is not guaranteed to win.

* Original source and checkpoints `src/image_model.py`, `src/temporal_model.py`, `best_pathology_cnn.pt`, and `best_temporal_lstm.pt` are protected by SHA-256 checks. Baseline training writes separately named benchmark checkpoints.
* Patient manifests must agree with both modalities and be pairwise disjoint. Original datasets are retained. Each tile file is content-hashed for cache provenance.
* All four pathology models use official ImageNet pretrained weights and the official preprocessing associated with those weights. The frozen encoder remains in evaluation mode. The identical 128-unit classification head is optimized by AdamW with cosine scheduling. A clean view and a reproducible color/noise challenge view are used for training. Validation and test images use deterministic transforms. Maximum 15 epochs, validation-based early stopping with patience six after at least ten epochs. This is frozen-feature transfer learning, not end-to-end fine-tuning.
* GPU extraction uses FP32, disables TF32, and uses 16-tile batches for the RTX 2050's 4 GB memory. Small cached heads and temporal networks use CPU optimization. Caches from the abandoned CPU extraction are retained under separate names and are not used to mix CPU/GPU timing comparisons.
* Existing patient bags contain every class and give a constant any-malignant label. A separate reproducible composition challenge draws 12 tiles from each patient's own sources without reading temporal outcomes. Dominant histology is the observed majority, with benign-first tie-breaking. Difficulty controls mixture probabilities. Repeated source tiles are recorded; this does not create independent real tissue. The existing synthetic generator does not establish a pathology/prognosis relationship.
* All input observations are day 0–90. Forecast landmark is day 90, with the measured ctDNA nearest day 120 within +/-12 days as the regression target. Missing targets are excluded with reasons, never converted into zero. Regression is an approximately 30-day landmark forecast; actual measurement dates are retained. Classification retains the generator's future-window biomarker progression label, not a clinically diagnosed recurrence label.
* Normalization uses historical training observations only. Imputation is causal forward fill with training means as fallback. Masks, velocity and intervals are recomputed after perturbations. Absolute and delta time retain day units; the upgraded Transformer also embeds visit indices. The original baseline BiLSTM architecture is unchanged, including its known padding limitation.
* Temporal models train for up to 20 epochs. Fusion models train for up to 40 epochs using batches of 32, AdamW, cosine scheduling and validation early stopping. Multi-task checkpoint selection minimizes validation SmoothL1 plus binary cross entropy. Pathology checkpoint selection maximizes validation macro-F1. Durations can be configured with `ONCOLOGY_PATHOLOGY_EPOCHS`, `ONCOLOGY_TEMPORAL_EPOCHS`, and `ONCOLOGY_FUSION_EPOCHS` before starting a new experiment namespace.
* Architecture selection maximizes validation progression F1, breaking ties by validation ROC-AUC and then lower ctDNA MAE. Single-modality and fixed-fusion systems are eligible. The probability decision threshold is fixed at 0.5. Test results are not used for any selection or tuning.
* Ablation A trains a progression/regression head using pathology alone; pathology-class F1 is never substituted for progression F1. E/F explicitly evaluate their paired pathology and temporal predictions. H evaluates the actual MC-mean prediction from G and adds OOD annotations; OOD does not manufacture a classification gain.
* Calibration is fitted only on validation. Undefined AUC or percent-degradation values remain undefined. Negative calibration/robustness changes are retained. MC dropout is uncertainty estimation, not a substitute for independently trained seeds.
* Seeds 42, 123 and 2026 independently optimize the selected learned fusion architecture. This measures fusion-head stability conditional on fixed seed-42 representations. It does not establish end-to-end multi-seed stability. Raw rows and sample SD are reported.
* OOD reference statistics come from training embeddings and thresholds from validation. Synthetic texture and controlled biomarker challenges are explicitly limited tests; they cannot establish detection of real clinical OOD cases.
* The API switches to validated inference only when final evidence artifacts exist. The preserved baseline remains explicitly selectable. Missing modalities use actual trained single-modality fallbacks; absent inputs return no prediction. Reliability artifacts must match the model they are applied to.

Run `dl/training/run_cuda_benchmarks.ps1` from the Stage 2 project to execute the GPU-preflight, experiments and evidence finalization. The installed `py` launcher does not discover Python 3.13 on this machine; the script uses its direct executable. API dependencies and the CUDA build are isolated in `.runtime` and `.cuda-runtime` under Stage 2.

Results and patient/tile-level predictions are saved under `results/validated_v3`. Separate model checkpoints are under `dl/checkpoints/validated_v3`. Completion, not merely the presence of a training log, is required before any final architecture claim.
