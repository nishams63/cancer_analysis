# Stage 5: Gen-AI — Evaluation Engineer

Responsible for evaluating downstream Stages 1–4 against Stage 5 synthetic oncology stress tests, computing sensitivity drop, discordance rates, and failure mode recall.

## Structure
- `src/`: Stress-test evaluation harness (`evaluator.py`) and metrics calculation (`metrics.py`)
- `benchmarks/`: Benchmark test cases and reference ground truths
- `results/`: Stress-test evaluation output records
- `reports/`: Comprehensive vulnerability reports
- `tests/`: Evaluation harness test suites
