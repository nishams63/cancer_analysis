# AADA Dashboard

Lightweight React + TypeScript + Vite + TailwindCSS frontend for the Autonomous AI Data Analyst.

## Core Answers
1. **What did I ask?** Goal input
2. **What is the agent doing?** Live run status & progress
3. **Why did it make this decision?** Live auditable trace timeline
4. **Does it need my approval?** Interactive Human Review modal (Approve / Reject / Override)
5. **What is the final result?** Structured findings, evidence classification, and independent evaluation scorecard

## Running Locally
```bash
cd frontend
npm install
npm run dev
```
