# Synthetic Clinical Audio Dataset Report

## 1. Executive Summary

This report documents the dataset creation and statistical distribution for **Stage 3 — Part B (Synthetic Clinical Audio)**. A real synthetic speech pilot was generated using approved clinical encounter narratives from the development split to enable speech-to-text (STT) benchmarking and downstream clinical NLP evaluation.

---

## 2. Audio Dataset Specifications

| Dimension | Specification / Metric | Description / Standard |
| :--- | :--- | :--- |
| **Total Audio Files** | **512 real WAV files** | Generated using native local Windows TTS engines |
| **Total Audio Duration** | **10.45 hours** (37,616.3 seconds) | Average duration: 73.47 seconds per audio file |
| **Source Clinical Notes** | **64 approved notes** | Sampled strictly from development cohort (48 TRAIN, 16 VALIDATION) |
| **Split Breakdown** | **384 TRAIN / 128 VALIDATION** | Strict inheritance: all 8 variants of a note share its split |
| **Locked Test Contamination** | **0.0% (Zero)** | Locked-test documents are strictly excluded |
| **Audio Format** | **WAV, 16 kHz, Mono, 16-bit PCM** | Industry-standard acoustic format for clinical speech models |
| **Number of Synthetic Voices** | **3 distinct voices** | `Microsoft Hazel Desktop`, `Microsoft David Desktop`, `Microsoft Zira Desktop` |
| **Acoustic Variants per Note**| **8 controlled conditions** | Normal, slow, fast, mild noise, moderate noise, pauses, volume, speaker |

---

## 3. Acoustic Condition Distribution

Each of the 64 source documents was synthesized under 8 controlled acoustic conditions, producing 64 samples per variant:

| Variant Identifier | Target Acoustic Modulation | Primary Purpose | File Count (Train / Val) |
| :--- | :--- | :--- | :---: |
| `clean_normal` | Baseline rate ($0$), volume 85%, clean studio condition | Reference baseline for clean audio | 48 / 16 (64 total) |
| `slow_speech` | Speech rate adjusted to $-2$ | Simulates deliberate/hesitant dictation | 48 / 16 (64 total) |
| `fast_speech` | Speech rate adjusted to $+2$ | Simulates rushed clinical emergency dictation | 48 / 16 (64 total) |
| `mild_noise` | Gaussian white noise ($\text{SNR} \approx 25\text{ dB}$) | Simulates ambient clinical room noise | 48 / 16 (64 total) |
| `moderate_noise` | Gaussian white noise ($\text{SNR} \approx 15\text{ dB}$) | Simulates clinic hallway / equipment hum | 48 / 16 (64 total) |
| `pause_variation` | Random silence insertions (0.2–0.5s) between sentences | Simulates clinician pauses and thinking time | 48 / 16 (64 total) |
| `volume_variation` | Random amplitude scaling ($\pm 6\text{ dB}$) | Simulates varying distance from microphone | 48 / 16 (64 total) |
| `speaker_variation` | Alternating synthetic voice gender/pitch profile | Tests multi-speaker generalization | 48 / 16 (64 total) |

---

## 4. Privacy & Data Protection Compliance

1. **De-Identification**: All source notes were pre-screened using `stage-3-nlp-slm/data-engineering/src/de_identification.py`. Zero direct patient identifiers (names, MRNs, phone numbers, addresses) were present in the synthesized audio.
2. **Safe Manifest Tracking**: Manifests in `stage-3-nlp-slm/audio/data/manifests/` track recordings using SHA-256 hashes of `document_id` rather than raw patient identifiers.
3. **No Clinical Overclaims**: All audio files represent synthetic experimental speech generated by speech synthesizers and do not represent recordings of real human patients or clinicians.
